# PR #61193 Fix: Exec Allowlist Glob Patterns

## Issue
Bug: exec approvals allowlist glob pattern not matching commands (#61193)

## Root Cause
In `matchAllowlist()` function (`src/infra/exec-command-resolution.ts`), patterns without path separators (`/`, `\`, or `~`) were being skipped entirely:

```js
const hasPath = pattern.includes("/") || pattern.includes("\\") || pattern.includes("~");
if (!hasPath) {
  continue; // ❌ Skips pattern without checking!
}
```

This caused patterns like `python3 *`, `bash -c *` to never match.

## Fix Applied
When a pattern has no path component, match against `executableName` or `rawExecutable`:

```js
if (!hasPath) {
  const execName = resolution?.executableName;
  const rawExec = resolution?.rawExecutable;
  if (execName && matchesExecAllowlistPattern(pattern, execName)) {
    return entry;
  }
  if (rawExec && matchesExecAllowlistPattern(pattern, rawExec)) {
    return entry;
  }
  continue;
}
```
