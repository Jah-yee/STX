## 发现的问题
credential-access 规则中的正则表达式有 bug：

```javascript
// 当前（错误）
pattern: /(?:\.ssh\/|id_rsa|\.aws\/credentials|\.env\b|\.npmrc|\.netrc)/

// 问题：\.env\b 中的点号没有转义
// 导致 "normalfile.env" 也会匹配（误报）
```

## 修复方案
将 `\.env\b` 改为 `\\\.env\b`（转义点号）
