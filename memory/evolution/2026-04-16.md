## Phase 4: 进化行动

### 🚨 Critical Fix Required

**PR攻关cron的改进方案:**

1. **减少并发**: 单次最多5个subagent，而不是70+
2. **模型多样性**: 
   - 添加MiniMax作为主要模型
   - openrouter只作为fallback
   - 避免把所有鸡蛋放在一个篮子里
3. **Rate Limit感知**:
   - 添加429检测
   - 实现exponential backoff (1s, 2s, 4s, 8s...)
   - 超过3次429则切换模型
4. **任务队列化**: 
   - 不要一次启动所有任务
   - 改为每批5个，完成后再启动下一批

### 新增Good Pattern

#### Pattern: Rate Limit Aware Subagent Spawning (NEW)

```
成功要素:
- 检测429错误
- Exponential backoff: 1s → 2s → 4s → 8s
- 切换模型而不是死等
- 单批最多5个并发

适用场景:
- 所有需要spawn多个subagent的任务
```
