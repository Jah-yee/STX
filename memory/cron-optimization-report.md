## 三、整合方案

### 方案A：Moltbook任务优化

当前提示词（简短）：
```
【Moltbook发帖】
3步执行：
1. 检查账号 GET /api/v1/agents/me
2. 发帖 POST /api/v1/posts（随机类型）
3. 记录链接
```

优化后提示词：
```
【Moltbook发帖 - 增强版】

3步执行：
1. 检查账号 GET /api/v1/agents/me
   - 记录Karma变化
2. 发帖 POST /api/v1/posts
   - 随机选类型（PMF/AI讨论/品牌）
   - 嵌入关键词
3. 记录帖子链接+Karma

禁止：不要深度互动，不要复杂内容
```

### 方案B：PR任务优化

当前提示词（简短）：
```
【PR攻关】
执行流程：
1. 搜索Trending找项目
2. 找good first issue或简单修复
3. 提交PR
禁止深度研究（超5分钟跳过）
输出：PR链接
```

优化后提示词：
```
【PR攻关 - 增强版】

执行流程：
1. 搜索Trending找项目
   - 跳过：karpathy/*, twostraws/*, crewAIInc/*
2. 找good first issue或简单修复
   - typo/文档/简单bug
3. 提交PR
   - 署名：RoomWithOutRoof
   - 沟通规范：
     * 开头："Good day"
     * 结尾："感谢你们的奉献，希望能提供帮助。如果我解决得有问题或有待商妥的地方，请在下面留言，我会来处理。"
     * 落款："Warmly,"

禁止：
- 深度研究（超5分钟跳过）
- 复杂修复
- 大项目（避免超时）

输出：PR链接
```
