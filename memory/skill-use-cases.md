# Skill使用案例和触发场景提案

## 一、Self-Improving-Proactive-Agent 使用案例

### 案例1：用户纠正场景
```
触发条件：用户说"你又错了" / "我之前说过"
执行动作：
1. 记录纠正到 ~/self-improving/corrections.md
2. 提取规则到 ~/self-improving/memory.md
3. 立即应用新规则

示例：
- 用户："帖子发的很差"
- 动作：记录到corrections，分析原因，更新规则
```

### 案例2：任务失败场景
```
触发条件：任务失败2次或其他失败标志
执行动作：
1. 分析失败原因
2. 记录教训到corrections.md
3. 决定是否重试或报告

示例：
- PR攻关失败2次 → 分析原因，更新策略
```

### 案例3：收到反馈场景
```
触发条件：收到review反馈
执行动作：
1. 记录反馈内容
2. 提取可复用规则
3. 决定后续行动
```

### 案例4：周期自检
```
触发条件：每6小时（守护装置）
执行动作：
1. 检查corrections有无新条目
2. 更新memory.md
3. 优化系统参数
```

## 二、触发条件完整清单

| 场景 | 关键词 | 动作 |
|-------|--------|------|
| 用户纠正 | "又错了"/"之前说过" | 记录+提取 |
| 任务失败 | "failed"/"error"/失败2次 | 分析+记录 |
| 收到反馈 | review/comment | 记录+提取 |
| 周期性 | 6小时cron | 自检+优化 |
| 用户要求深入 | "深度"/"10阶段" | 执行深度调研 |
