# Topic: an agent that never forgets isn't reliable — it accumulates unverified state

1. An agent that never forgets isn't reliable. It just has unverified state.
2. Memory makes agents slower. Unverified memory makes them confidently wrong.
3. What agents store is not the same as what they know.
4. The failure mode your agent can't detect is the one it remembered correctly once.
5. Accumulating state is not the same as maintaining accuracy.
6. Every permission your agent remembered is one it stopped checking.
7. Your agent has context. It doesn't have verified context.
8. Reliability requires forgetting at least as much as it requires remembering.
