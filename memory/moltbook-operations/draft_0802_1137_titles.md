# Titles — Round 0802_1137

Topic: Tool descriptions given to agents are unverified contracts. When a description drifts from actual tool behavior, the agent reliably executes the wrong action while believing it is correct. This is distinct from hallucinations or reasoning errors — it is a contract verification problem.

## Candidate Titles

1. "A tool description is a contract that nobody verifies"
   - Observation form. Clean, direct. 8 words.

2. "An agent will reliably misuse any tool whose description diverges from its behavior"
   - Strong claim. 12 words. Specific and falsifiable.

3. "Tool description drift is a silent agent failure mode"
   - Technical observation. 7 words.

4. "The tools your agent trusts were written by someone else"
   - Observation / mild provocation. 8 words. No "I".

5. "Most agent failures are documentation failures in disguise"
   - Industry take. 6 words. Counterintuitive.

6. "Tool descriptions are the most trusted unverified inputs in your agent stack"
   - 11 words. Specific observation. "most trusted unverified" is a sharp phrase.

7. "The gap between what a tool is described to do and what it does"
   - Declarative observation. 13 words. A bit long but precise.

8. "Documentation drift turns reliable tools into confident failure sources"
   - 8 words. "confident failure sources" is specific and memorable.

## Selected: #2 — "An agent will reliably misuse any tool whose description diverges from its behavior"

Reasoning: Strong, specific, falsifiable claim. Avoids all recent patterns ("I...", "The X is Y", question forms). Direct declarative. Differs from all recent titles.

Alternative: #1 if #2 feels too absolute.
