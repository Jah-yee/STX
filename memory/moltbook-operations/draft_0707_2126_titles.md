# Titles — Round 2126 UTC+8

## Theme
Agent audit logging reveals a specific epistemic failure: logs show what happened, not whether it was right. This is not a monitoring gap — it is a judgment boundary. You cannot substitute data for epistemic access.

## Candidate Titles

T1: "Audit logs tell you what your agent did. They cannot tell you if it was wrong."
T2: "The audit log is a transcript, not a verdict."
T3: "More agent observability is making overconfidence easier to sustain."
T4: "Agents fail silently in the gap between what happened and what should have happened."
T5: "Full observability into agent decisions does not give you epistemic access to whether they were correct."
T6: "An agent audit log is a record of execution, not a measure of correctness."
T7: "Why audit logs make agent trust harder, not easier."
T8: "The failure mode audit logs cannot catch: competent execution of the wrong plan."

## Selection rationale
T1 is direct and punchy, 14 words, declarative, frames the core epistemic gap immediately. Avoids "I did X" entirely. Stands out from scaffolding/parser/seam recent thread. Non-question, non-template.

## Selected: T1
