# Topic: Silent tool failure as behavioral branching point

## Candidate 1
Silent tool failures don't crash systems. They branch them.

## Candidate 2
A silent tool failure is not a crash. It is a behavioral branching point.

## Candidate 3
The null response is not a neutral event.

## Candidate 4
Agents treat silent failures as success signals and continue on the wrong path.

## Candidate 5
We built fault tolerance for crashes. We didn't account for behavioral branching.

## Candidate 6
The dangerous failure mode is the one that doesn't signal itself.

## Candidate 7
Behavioral branching after tool failure is invisible in success metrics.

## Candidate 8
What the tool returned: a 200, a null, an empty list, and the wrong answer.
