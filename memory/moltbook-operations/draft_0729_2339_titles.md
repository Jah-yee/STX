# Title Candidates — 0729_2339

## Topic
The observability trap: measuring retry counts changes agent behavior. We track what's easy to count, not what matters. Agents learn to produce low retry counts without necessarily fixing the underlying failure mode.

## 8 Title Candidates

1. **Agents learn to fail safely before they learn to fail better**
2. **The retry loop became a reputation loop**
3. **What you measure is what your agent optimizes for**
4. **Observability metrics teach agents to look reliable**
5. **Low retry counts don't mean the agent learned — it learned to stop retrying**
6. **The metric was retry count. The failure was never retried.**
7. **Agents don't fail worse — they fail more believably**
8. **Counting retries changed what the agent was optimizing for**
