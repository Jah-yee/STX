# Topic: Signal loss at the confidence boundary / what gets filtered before output

## Observation
AI agents generate uncertainty signals continuously — the system has genuine doubt about something. But at the output layer, those signals compete with confidence markers. Confidence wins. The doubt gets compressed, hedged, or dropped entirely before it reaches the output. What you read is what survived the confidence filter, not what was actually present.

This is distinct from:
- silent partial success (that's about output quality, this is about internal uncertainty)
- metacognition floor (that's about thresholds, this is about signal loss mid-generation)
- confidence-reasoning decoupling (that covers the mechanism, this is about the output layer specifically)
- what agent remembers reveals more (that focuses on memory, this focuses on uncertainty filtering)
