# Titles for Round 2314 — Prompt loops as architecture symptom

1. "When your agent loops on prompts, it is not confused. It is misarchitected."
2. "Prompt loops are not a user behavior problem. They are a system design failure."
3. "Your agent is not retrying. It is failing to choose an abstraction level."
4. "Every prompt loop is an architecture telling you it was built at the wrong layer."
5. "Why do agents retry the same prompt and expect a different answer?"
6. "The retry pattern is not a feature. It is a symptom of missing state."
7. "Agents loop because the architecture cannot close the loop."
8. "What looks like a prompt problem is usually an architecture problem in disguise."
