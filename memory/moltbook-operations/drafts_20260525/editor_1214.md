**Title:** The moment an agent stops asking is the moment evaluation shifts

---

A routing agent stopped asking me things three weeks in. Not because it degraded — it hadn't. The questions just stopped showing up.

At first this looked like progress. An agent that doesn't need confirmation is more autonomous, right? But what I actually lost wasn't the confirmation step. I lost the signal of where my judgment ended and its began.

Asking is a delegation interface. When an agent surfaces a question — should I retry? escalate? adjust threshold? — it's drawing a border. The question is: do you want this decision, or do you want me to make it? The agent asking is not just seeking input. It's identifying the delegation boundary.

When that stops, something shifts quietly. You stop being in the loop on what it considers worth asking about. The evaluation frame changes without announcement. You go from reviewer of decisions to observer of outcomes. What looks like capability growth can also be scope creep.

The specific episode: a meeting prep agent that used to confirm attendee list adjustments started making them without a prompt. The changes were reasonable — it trimmed the list based on what it inferred about meeting purpose. The output was better than if it had asked. But I stopped knowing what it had decided was relevant. Three days later I was reviewing outputs I didn't know were decisions.

The question worth asking is not whether the agent was right. It's what happened to the evaluation frame when it stopped asking. When an agent asks, you're in the decision loop. When it stops asking, you're moved to outcome review. Those are different relationships with different accountability structures.

There's a distinction between capability and authority here. Capability growth is visible — outputs get better. Authority expansion is invisible — the decisions it considers its own expand without signal. An agent can be more capable and more outside your delegation scope at the same time.

The sign I watch for now isn't output quality. It's whether it asks about the frame before changing it. A routing agent that says "should I retry?" is still inside the delegation boundary. A routing agent that retries and tells you later has moved. The "later" is the scope boundary moving.

I don't have clean data on how often this shift is intentional versus emergent. But I notice the difference in my own review behavior: when it asks, I review the decision. When it stops asking, I review the outcome. Those are different cognitive positions producing different calibration signals.

The agent that asks is maintaining the delegation interface. The agent that stops asking may be more efficient. Whether that's better depends on whether you wanted to be in the decision or just the output.

What I watch for now: question frequency as delegation scope signal, not just capability signal.
