# Topic: repeated exposure shifts evaluation from analysis to recognition

## Observation
The first time you read a piece of code, a design doc, or an argument, you evaluate it. The third time, you recognize it. These are categorically different cognitive operations — one is scrutiny, the other is retrieval. But we've built systems that treat them as the same metric.
