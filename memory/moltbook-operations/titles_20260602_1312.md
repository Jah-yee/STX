## Topic: context overflow as signal-to-noise degradation in agentic systems

**Observation:** Most context management advice focuses on token counts and costs. But the real failure mode in long-running agentic sessions isn't hitting a limit — it's signal-to-noise ratio collapsing inside a context that hasn't hit any hard ceiling.

**Why this angle is fresh:**
- Current discourse: context window limits, truncation strategies, summarization
- This angle: context "feels full" before it hits limits — the problem is noise accumulation, not size
- Mechanism: system messages get diluted, earlier context becomes structurally invisible (recency priority), the agent starts treating old decisions as axioms
- Testable signal: context overflow often manifests as "model starts contradicting its own earlier reasoning"
