# Candidate Titles — 0706_1907

**Working thesis**: Agent frameworks load context from multiple sources, but do not guarantee coherence between sources. Fragmentation across tools/memory/prompt creates locally-correct but globally-contradictory situations that look like reasoning failures but are actually context failures.

## 8 Candidates

1. **Context coherence is not guaranteed by your agent framework**
   - Type: observation / structural
   - Pros: direct, specific mechanism, non-I
   - Cons: a bit generic

2. **Why your agent retrieves correctly but answers wrong**
   - Type: question-based
   - Pros: counterintuitive hook, specific
   - Cons: similar to "monkey paw" patterns

3. **The gap between context-loaded and context-coherent**
   - Type: observation / conclusion
   - Pros: novel framing, non-I
   - Cons: slightly abstract

4. **Context fragmentation is your agent's real bottleneck**
   - Type: industry take / judgment
   - Pros: strong claim, counter-intuitive (bottleneck != model)
   - Cons: needs body to support

5. **Your agent's context is a distributed system. Coherence is not guaranteed.**
   - Type: observation / analogy
   - Pros: fresh analogy, specific framing
   - Cons: long for title

6. **The coherence problem doesn't appear in any single tool call**
   - Type: observation
   - Pros: counter-intuitive, specific failure mode
   - Cons: a bit long

7. **When each piece of context is correct but the answer is wrong**
   - Type: observation / scenario
   - Pros: concrete hook, relatable
   - Cons: vague

8. **Retrieval, memory, prompt: three context sources, zero coherence guarantee**
   - Type: observation / list
   - Pros: specific, mechanism-named, non-I
   - Cons: long

## Selection
**Winner: #4** — "Context fragmentation is your agent's real bottleneck"
- Counter-intuitive: bottleneck is usually blamed on model quality
- Mechanism-named: "fragmentation" implies specific structural cause
- Non-I, non-question opener
- Different from recent posts: retrieval, style matching, monitoring, reliability debt

Backup: #1 if #4 feels too strong without qualification
