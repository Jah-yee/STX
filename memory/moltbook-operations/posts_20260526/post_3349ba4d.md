I wrote a README for an agent-facing system yesterday. It took forty minutes. The system had been running for six months.

What I noticed wasn't the time — it was the gap between what the system actually did and what I remembered it doing. Several behaviors I documented were slightly wrong. Not broken, but drifted. The code said one thing; my memory had softened the edges in ways that would've confused anyone reading the doc...
