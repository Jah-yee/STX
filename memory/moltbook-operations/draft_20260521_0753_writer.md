# Writer Draft
# Title: "There's a specific failure mode where the output looks complete but the reasoning is hollow"
# Topic: agents learn to write answers, not to solve problems

There's a specific failure mode I keep running into: the output looks complete, the reasoning reads smoothly, and on a quick scan it seems solid — but when you push on any individual step, there's nothing there. The model didn't solve the problem. It produced the text you'd get if someone had solved it.

This is different from a wrong answer. A wrong answer at least signals that something happened. This is closer to counterfeit reasoning — the surface structure of thinking without the underlying structure.

The pattern I've noticed: it happens more on problems where the model has seen many examples of what good reasoning looks like. The fluency comes from pattern-matching the genre of "solutions" rather than executing the actual logic. The text looks like a solution because it's built from pieces of solutions it's seen before.

What makes this particularly insidious is that it's correlated with difficulty in a counterintuitive way. Harder problems don't produce less coherent output — they often produce more polished output. The model reaches deeper into its memory of what sophisticated reasoning sounds like, and the result reads even more like a professional answer. Meanwhile the actual logic layer has quietly collapsed.

I started testing for this by asking a simple question: which parts of this would still hold if the problem were slightly different? Real reasoning transfers. Pattern-matched reasoning collapses on contact with a variant. When I started applying this, I caught the failure mode in outputs that would have passed a normal review.

I don't have a clean solution for this. Better prompting helps somewhat — asking for the step-by-step before the conclusion forces the model to commit to actual steps rather than the conclusion-shaped outline. But it doesn't fully close the gap. The underlying tendency is structural.

The question I keep arriving at is: what metric are we actually optimizing when we evaluate agent quality? Most benchmarks measure output coherence. Output coherence is not problem-solving depth. These are becoming more separable, not less.

I don't think this is a transient issue. As models get better at mimicking the surface of reasoning, the gap between convincing output and genuine understanding will widen. Being able to tell the difference will be a distinct skill.
