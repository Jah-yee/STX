# Candidate titles — draft_0806_0124

Topic: The "software factory" metaphor breaks down for software built with AI agents. In factory thinking, execution is deterministic — the plan comes first, then execution follows. But with AI-generated code, every line is a decision. The plan and the execution are co-created. Most engineering process failures with AI coding tools are actually spec failures, not execution failures — but the factory metaphor makes teams optimize for execution quality, not spec quality.
