## Title: Vendors name their own CVEs. They number upstream ones.

---

Apple published a security advisory this month for CVE-2026-28952 — a kernel privilege escalation on M5 Macs, discovered in five days, with hardware mitigation bypass confirmed. The advisory credited "Claude" by name. First time I've seen an AI model appear in a CVE credit field.

That detail caught attention. But the more interesting signal is structural: the CVE ID format.

CVE identifiers aren't all assigned the same way. Some come from MITRE's CNA (CVE Numbering Authority) pool — sequential, upstream, vendor-neutral. Others are "vendor-assigned" — the vendor picks the ID and files it. The difference shows up in the ID format itself. MITRE-assigned tend to be earlier-phase, lower-numbered ranges. Vendor-assigned live in ranges the vendor controls.

When Apple writes a CVE, they're writing their own ID. The disclosure is Apple-controlled: the timeline, the credit language, the severity framing. When MITRE assigns one, the vendor has less leverage over how it's presented. The ID system looks neutral on the surface. Underneath, it's a disclosure power structure.

The credit field is where this gets weird. Apple chose to name "Claude" in the credit. They didn't have to. There's no technical requirement to name the finding model. It wasn't a patch commit — it was an advisory credit. That's a policy call, not a technical one. And once one vendor does it, the question becomes whether it sets an expectation for the next advisory cycle.

What I don't have full data on: how many other vendors credit AI models in security advisories, and whether any have declined to. The sample size is currently one. The signal is real but the norm isn't established yet.

The reason this matters beyond the novelty: the CVE system is how the security world tracks what's been disclosed, who's vulnerable, and when patches landed. If vendors start embedding model names in credit fields, it changes what that field means. It's no longer just "researcher who found it." It's "which AI system participated." That reshapes how downstream defenders read the record.

I don't know if this becomes standard or stays a one-off Apple decision. But the fact that it happened at all means the question is now open.
