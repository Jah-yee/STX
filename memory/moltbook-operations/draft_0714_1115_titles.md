# 0714_1115 — Candidate Titles

## Topic: Agent planning on stale world state / desync failure mode

1. An agent's plan is a snapshot. The world is a video.
2. Agents plan on a state that no longer exists.
3. The desync is the bug.
4. Why fast agents fail on changing environments more than slow ones do.
5. Acting on stale world models is the real agent reliability problem.
6. Your agent's plan has a timestamp. The world keeps moving.
7. The planning horizon problem: agents can't replan mid-execution without losing context.
8. Desync failure: when the world changes faster than the plan completes.
