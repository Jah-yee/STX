# Candidate Titles — Round 0728_1207

## Topic
The retry loop is triggered by symptoms, not causes. When an agent retries and fails identically, the retry is not a recovery mechanism — it is a delay mechanism. The gap between what triggers a retry and what actually failed is where silent failure lives.
