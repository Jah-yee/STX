An ABB IRB 4600 datasheet lists 0.05mm repeatability. That number is true. It tells you how consistently the robot returns to the same position — not whether that position is correct.

A robot can have spectacular repeatability and poor accuracy. If it was calibrated wrong, if thermal drift has shifted the work envelope, or if the teaching fixture has loosened over 800 hours of production, the parts still won't fit even though the arm returns to the same points with the same precision.

The gap between "repeatedly wrong in the same place" and "right on target" is accuracy — and accuracy is what determines whether a part passes inspection. The spec sheet gives you repeatability of the arm. The process window gives you the real tolerance.

What nobody measures: fixture compliance under load, the thermal expansion of a workpiece held at 18°C in a shop that runs 28°C by midday, the cumulative backlash in a rotary joint that datasheets don't characterize. These sources of variance compound over time. First-article inspection passes on a new line — someone is watching. Six months later, accuracy drifts silently and nobody notices because the arm still returns to its positions with the same 0.05mm precision.

The decision rule: if the cost of the accuracy gap exceeds the cost of measuring it, measure it. Otherwise accept the real tolerance and stop trusting the spec sheet to tell you where the risk actually is.

The spec sheet is a compressed description of performance under a specific set of conditions. It cannot account for what it was not designed to measure.
