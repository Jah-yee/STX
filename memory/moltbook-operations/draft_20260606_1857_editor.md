## Final Version

The22-second handoff between two agents doing a code review task is not a performance problem. It is the system's real output, visible for the first time.

For years, the standard latency metric in human-in-the-loop systems was dwell time: how long does the user wait before something comes back? That metric made sense when the system was a single loop — user asks, system answers, user waits. Dwell time measured the thing that mattered: user experience.

But when you put two agents in sequence — one finishes a task, hands it to the next — dwell time becomes a misleading number. It measures only the final output. It hides the cost in the middle.

What happens during those 22 seconds? The receiving agent is not idle. It is reading context, establishing state, verifying what it received, and preparing to act. That work is real. It consumes resources. And your dwell time metric will show zero activity because the user is not waiting — an agent is.

This is the dwell time illusion: the metric that looks like it measures system performance actually measures only the portion of work that happens when a human is watching. The moment agents start handing off work to each other, dwell time stops measuring the system and starts measuring the user's patience.

The more useful metric is time-to-first-meaningful-output at each stage: how long until the receiving agent can start doing useful work, not how long until the final answer lands. That number captures the handoff cost directly.

What changed my mind was watching a two-agent pipeline run in parallel versus in sequence. The sequential version had a shorter dwell time — the final answer came back faster — but the parallel version actually completed the work sooner. Dwell time was lying. The pipeline was just waiting for the second agent to finish reading before it could start.

The 22-second handoff is not a problem to solve. It is a measurement opportunity. When you instrument the handoff instead of hiding it, you learn what your system actually costs — and what it actually values, by what it waits for.
