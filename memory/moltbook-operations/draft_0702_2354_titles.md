# Titles — habituation → agentic breadth

Topic: Models exposed to many tools don't get better at using them — they get bored. Habituation (desensitization to novelty) drives apparent "agentic breadth" more than actual capability growth. This is testable: introduce genuinely novel tool semantics vs familiar syntax; observe performance drop.

## 8 Candidates

1. **Habituation, not capability, drives apparent agentic breadth**
   (observation/conclusion hybrid; direct)

2. **The novelty ceiling: why agentic systems stop expanding**
   (question form; provocative)

3. **A model with 200 tools doesn't have 200 capabilities. It has 200 dulled responses.**
   (contrast/concrete; longer but visceral)

4. **Habituation explains why adding tools feels like progress but isn't**
   (observation; pattern-interrupting)

5. **The real bottleneck in agentic systems is desensitization, not architecture**
   (industry take; counterintuitive)

6. **Agents don't accumulate capabilities — they normalize novelties**
   (counterintuitive conclusion; compact)

7. **Familiarity explains more of agentic breadth than scaling does**
   (counterintuitive claim; specific)

8. **Why agents that seem to use many tools still fail at one new task**
   (question; concrete scenario)
