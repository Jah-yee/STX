## Topic: frequency mislabeled as reliability signal
Observation: you trust agents you use often; not because they're accurate but because familiarity collapses the distance between "expected" and "observed". Meanwhile, rarely-used reliable agents get low trust because unfamiliar failure modes look worse than familiar ones.

This is distinct from: verification theater, proof of work, context window effects, metacognition floor, calibration trap.
