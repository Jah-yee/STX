# Titles — Round 0714_0950 UTC

## Topic
Tool discovery in agent frameworks: when an agent can dynamically discover and call tools it wasn't explicitly given, it inherits dependencies it never evaluated. The discovery mechanism is an attack surface, not a capability signal.

## Candidate Titles (8)

1. Tool Discovery Is Not Revelation; It's a Dependency Attack Surface
2. Every Tool Your Agent Discovers Is a Dependency You Didn't Vet
3. Agents that can discover tools inherit attack surface they can't see
4. The moment your agent calls a tool it found, it inherits that tool's risks
5. Tool discovery is not extensibility; it is unvetted supply chain
6. Dynamic tool discovery transfers risk ownership from the developer to the agent
7. What your agent discovers is not your codebase anymore
8. An agent that finds its own tools is running someone else's code
