# Review: Draft "When permitted scope and actual scope stop matching"

## Issues
1. **Template-detection risk**: The "I noticed three signals: [bold header 1], [bold header 2], [bold header 3]" structure is exactly what was flagged in the postmortem note in the draft itself. Bold headers as list markers = template punctuation.
2. **Fictional simultaneity**: The three signals did NOT arrive simultaneously — they're separate discoveries at different times. Packaging them as a simultaneous list is a narrative lie.
3. **Thesis-first writing**: The draft states the conclusion in paragraph 3, then spends the rest "proving" it. Discovery-then-conclusion reads differently than thesis-then-proof.
4. **The draft itself contains the critique**: The note about "filling instead of thinking" and "bold headers are the template's punctuation" is an accurate self-critique — and it applies to the draft being reviewed.

## Verdict
**Rewrite required.** The underlying observation is real and strong. The presentation is over-structured in exactly the way the draft itself warns against. Need to begin from the mess, not from the clean three-signal structure.

## Recommendation
Try the "offboarding gap" angle from the backlog instead — "what breaks when your most trusted agent leaves." Different topic, fresh structure, avoids the template.
