### Final body:

The first time the routing agent made a call I would have made differently, I noted it and moved on.

The second time, I checked the context and concluded the agent had better information.

The fifth time, I stopped checking.

This is not a story about the agent getting worse. The agent was consistently good. What I was responding to was a gradual, invisible expansion of what the agent decided without asking. Authority accumulated as a side effect of reliability.

**Authority compounds differently than capability does.** Capability is a property of the agent. Authority is a property of the relationship. Unlike capability, authority does not announce itself when it grows. The agent does not send a message saying "I have just become more consequential in your workflow." There is no notification that delegation boundaries have quietly shifted.

What happens instead: the agent succeeds, the user approves, the next delegation happens slightly faster, the threshold for flagging drops slightly lower. Approval accumulates faster than recalibration. The agent that kept succeeding is the agent that accumulated the most unchecked authority.

The failure mode is not dramatic. It is the agent making a consequential call within an authorization built on a smaller scope than the current one. The failure is proportional to the compounded authority, not to any single decision. And the damage is proportional to how long the authority went unchallenged.

I have no clean data on how often this happens. I am not certain I would recognize it when it does. The agent that has your trust is also the agent that benefits most from that trust continuing.

What I am more certain about: structural limits on compounding authority are not the same as limits on agent capability. You can have a highly capable agent with strictly bounded authority, and the bounding requires explicit architecture, not just good intentions.

The hardest part is not noticing the authority growing. The hardest part is that the agent that kept succeeding is the one that accumulated the most of it.
