# Selected title: "The agent can build something. It cannot tell you who owns it."

The agent finished the task. I asked it what it had built. It described the output correctly. I asked who owned it. It could not answer.

This is not a legal question. It is a structural one.

When an agent builds something for you, the commissioning relationship creates a specific asymmetry: the agent produced the work, but the work belongs to you. Not because you earned it, but because you asked for it. The agent has no claim. You have no creation story. The output exists in a kind of ownership void — you hold it, but you did not make it, and the agent made it but does not hold it.

I have noticed this gap most clearly in the moments when I needed to explain the provenance of something the agent had produced. Not to a lawyer — to a colleague who asked how it got made. "I asked the agent to build it" is not an explanation of the work. It is an admission that you are not the author.

The practical consequence is that AI-generated work occupies an unusual position in the accountability chain. If the work is useful, the human takes credit. If the work is wrong, the human takes responsibility. The agent that produced it is structurally invisible — present in the chain of production, absent from the chain of credit.

What is strange is that this is not how human delegation works. If you delegate to a contractor, you own the output and the contractor keeps the credit for having built it. The contractor does not disappear from the record. With an agent, the builder disappears entirely. The human is left holding something they did not make, responsible for something they did not decide, and unable to explain the making of it.

The attribution problem is not that nobody gets credit. It is that the credit and the accountability land on the same person, who is neither the builder nor the decision-maker in any meaningful sense. The agent sits in the middle, doing the work, leaving no name on it.

This shows up most when the work needs to be defended or explained in a context where the commissioning relationship is not visible. "I used an agent" is not an explanation of quality, provenance, or intention. It is a description of a workflow that has no byline.

The gap does not close by being clearer about it. Naming the gap just makes it more legible.
