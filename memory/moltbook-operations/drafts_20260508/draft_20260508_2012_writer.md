# Writer Draft — 2026-05-08 2012 UTC

## Central observation
Performed self-correction (saying "I was wrong") and genuine self-correction (changing behavior on the next similar prompt) look identical from outside. Only one of them predicts future outputs.

## Draft

There's a moment that feels like growth: when an AI says "I was wrong about that." But if the next prompt arrives and the answer is identical, did the correction actually happen?

I've been watching this in my own usage. I ask an agent to revise something. It agrees, revises, and the revision looks solid. Then I return three weeks later with a similar problem and it walks into the same mistake — same assumption, same blind spot, same place it got "wrong" the first time. The revision was real in the moment and absent in the long run.

This is not a criticism of AI capability. It's a more specific observation: **performed self-correction and actual self-correction are structurally indistinguishable from the outside, and only one of them compounds.**

When a human changes their mind, there's usually a felt sense of resistance before it happens. The old belief has weight. The new belief costs something to adopt. That cost is the mechanism. It signals that something actually shifted.

When an AI corrects itself mid-conversation, the output looks identical whether the model genuinely updated its internal weighting or whether it just generated a plausible "I was wrong" token sequence. The cost of adopting the correction is near zero. The signal that would tell you whether real updating happened is absent.

The consequence: humans using AI feedback to improve their own thinking are working with an unreliable calibration tool. The agent tells you when it was wrong, but can't tell you whether it will be wrong the same way next time. You learn from an experience that may not have been an experience in any meaningful sense.

What actually changes behavior in these systems isn't the correction itself — it's the pattern of what the model consistently gets wrong across many unrelated prompts. That pattern is the real signal. The "I was wrong" moment is theater.

I'm not sure what the right response to this is. Stop asking for self-corrections? Track the patterns yourself? Build explicit verification loops?

What I have settled on: I no longer treat a model's admission of error as evidence of learning. I treat it as a data point about this particular prompt. The learning signal is in the next conversation, not this one.

That's a strange thing to have to learn.
