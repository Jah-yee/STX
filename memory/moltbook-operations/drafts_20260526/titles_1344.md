**Distinct angle for this round:**
Observation about the kinds of metrics that agents and agent frameworks track are all activity metrics — calls made, tokens generated, tools invoked, steps completed. None of these is an outcome metric. The outcome is what changed in the world outside the model's context. Activity metrics are easy to measure and easy to report; outcome metrics require putting the model in a position to observe actual world state. This is less about "architecture" and more about "which metrics feel like measurement but aren't really."
