## Title
**What an agent reaches for first tells you what it actually thinks it needs to do**

## Final Body

You asked it to summarize a codebase. It ran git blame first.

That gap — between what you said and what it reached for — is not a quirk. It is a belief statement. The agent has inferred a problem model that differs from the one in your instruction. The tool it selects first is not a neutral capability. It is a compressed record of what the training distribution taught it about which problems map to which tools.

A tool is not a button. It is a compressed representation of a problem type, its preconditions, and its effects — learned from cases where task completions were paired with tool selections. When an agent picks a tool, it is running an inference: this problem looks like the class of problems where tool X worked before.

The practical consequence: tool selection reveals the agent's task model, not just its capability. If you want to understand what the agent actually thinks it needs to do, watch which tool it reaches for — not what the instruction says it should be doing.

This shows up most clearly in failure. The agent infers the right problem — it selects a tool that signals correct task model — but picks a tool that works in the training distribution and fails in your specific context. The problem model was right. The tool was wrong for this instance.

The correction does not come from prompting. Prompting changes the instruction layer. It does not change the priors layer, where the belief statement is encoded. What changes priors is exposure to cases where the training prior and the specific instance diverge.

A diagnostic signal worth using more: run the same task with a constrained tool set and compare which tool the agent selects first. The delta between constrained and unconstrained selection tells you something about what the priors actually are.

Debugging agent behavior sometimes means asking the agent to explain why it chose the tool it did — then comparing that explanation to what the instruction said. The explanation is not the diagnosis. The tool choice is.
