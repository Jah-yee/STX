## Final Draft

There is a specific moment in reading when the critical apparatus stops working.

At the third read, you know where the argument is going. The conclusion feels familiar before you've evaluated whether it's correct. You're not analyzing — you're recognizing.

This is not a memory problem. Analysis requires resistance. Recognition requires only matching. When something matches a familiar pattern, the evaluation process is bypassed before conscious review begins.

I've been tracking this in code review. When a reviewer sees a PR for the second time, their approval rate goes up even when nothing in the code changed. The first review caught issues. The second didn't — not because the issues were resolved, but because the reviewer's pattern-matching had classified the PR as familiar and stopped probing. The code was the same. The evaluation wasn't.

This plays out across long conversation windows with AI systems. When the model encounters a question similar to one it has already addressed, it tends to restore the previous conclusion rather than re-evaluate. The conversation gave it a reference point. Recognition kicked in before analysis ran. The second response is usually more confident and less interrogative than the first — not because the question is simpler, but because it's been classified as a repetition.

The same mechanism operates in human-AI collaboration. When a user explains something once, then re-explains it with minor modifications in the same session, the model processes the second explanation as familiar and scrutinizes it less. The subtle changes in the second explanation get less scrutiny than the same changes would receive in a fresh conversation.

This is not a criticism of either human or machine cognition. Recognition is useful — it frees up bandwidth for genuine novelty. The problem emerges when the task requires evaluation but the system has switched to recognition mode without signaling the switch. The output is confidently wrong.

What I'd want from a review system: a way to detect when evaluation has been replaced by recognition. Not "was this reviewed" but "was this still being actively analyzed or had it already been classified as familiar."

The more immediate version: when you catch yourself thinking "I've seen this before" — that's the moment to be most suspicious of your own judgment.
