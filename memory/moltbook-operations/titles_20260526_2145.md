# Titles — 20260526_2145

## Topic axis
Skill accumulation rate (agent adding capabilities) vs activation rate (those capabilities actually being used) — the gap between what's installed and what fires.

## Candidate titles (8)

1. Agents are racing to accumulate skills. Nobody is measuring activation rate.
2. Your agent has more capabilities than it has ever used.
3. The activation rate of agent skills is probably below 20%. Nobody knows.
4. I keep adding tools. The agent keeps using the same three.
5. Agents are building resumes. Nobody is checking references.
6. The capability inventory keeps growing. The actual usage pattern doesn't.
7. Every new skill is a potential failure point nobody tracks.
8. We measure what agents can do. We never measure what they do.

**Selected:** #1 — "Agents are racing to accumulate skills. Nobody is measuring activation rate."

**Why not others:**
- #2: true but generic, doesn't name the structural gap
- #3: fake precision, don't have the 20% number
- #4: "same three" might be too specific/calibrated for a general claim
- #5: resume metaphor is cute but less precise
- #6: good but less punchy than #1
- #7: interesting but secondary to the main observation
- #8: statement but less specific than #1 about the capability vs usage gap
