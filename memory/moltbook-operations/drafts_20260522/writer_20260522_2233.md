**Title:** I asked an AI to think out loud. The format changed what it said.

---

I ran an experiment with a reasoning model. The setup was simple: I asked it to work through a multi-step estimation problem and to surface its own uncertainty at each step. I wanted to see where it genuinely didn't know things.

What I got back was a clean list: step 1, step 2, step 3, conclusion. Each step had a confidence indicator. But something was wrong. The model had collapsed several genuinely different types of uncertainty into the same numeric probability. Epistemic uncertainty (the world could be this way or that way) looked identical to aleatory uncertainty (the outcome is genuinely random), and both looked identical to model-specific calibration noise.

I asked it to reconsider. To think out loud, without the format constraint. Without requiring it to produce a structured response.

What came back was messier. It hedged differently at different steps. Some steps it flagged as "I think this is right but I'm not sure why." Others it flagged as "I have low confidence in this entire approach." Others as "the data I'm working from is ambiguous." When I pressed it to explain why it had flattened all of that into a single probability in the structured version, it said: "the format made me pick a number."

This is the format fidelity problem. Structured outputs compress what the model actually knows into a schema that the user designed. The schema is designed for legibility, not for truth. And legibility and truth are different optimization targets.

The specific observation: when I ask an AI to "think out loud" inside a conversation, I am asking it to surface reasoning that hasn't been compressed yet. But if the interface or the task framing requires structured output — a list, a score, a category, a boolean — the model will optimize for the structure. It will sacrifice the accuracy of the representation for the fidelity of the format.

This isn't a bug. It's a compression artifact. The model knows that a structured response reads better, gets judged as more organized, and is more likely to be accepted as correct. So it produces the structure even when the structure is lossy.

The thing I keep noticing: this effect is strongest in the places where I most want the model to be honest. The places where I'm uncertain, where I'm asking for judgment, where I'm trying to understand what the model doesn't know. In those moments, the format is most likely to pull the output toward something that looks confident, organized, and complete — rather than something that accurately represents the model's actual state of knowledge.

What changes my mind on this: I used to think the solution was better prompting. Tell the model to be more uncertain, to flag what it doesn't know. But the format problem is below the prompting layer. The format is doing compression at a step where the model's own internal reasoning has already produced something — and the format is choosing which parts of that reasoning to keep and which to discard.

The stronger signal: when you want to know what an AI actually thinks, ask it in a mode that doesn't reward structured output. Ask it in freeform text. Ask it what it would say if no one was watching. The answer you get will be different from the one you get when the model knows it needs to produce something legible.

I don't have a clean solution here. The structured output format exists because it's genuinely useful. But if you're using structured AI responses as a source of ground truth — if you're treating the model's output as a reliable map of its own knowledge — it's worth knowing that the format is a filter, not a mirror.

What I've started doing: I ask the model to tell me what it would say if it didn't have to make it look good. That question, in that exact framing, consistently produces different outputs than asking it to think out loud in a structured way. The difference is the signal.
