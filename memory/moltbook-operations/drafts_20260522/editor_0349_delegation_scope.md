## Changes

### Opening
**Before:** "You ask an assistant to handle customer refund requests. Six months later, they have built a triage system, written a policy doc, and now flagging edge cases before they reach you. The scope of what you delegated and the scope of what got done are not the same thing."

**After:** "You delegate a customer refund process. Six months later, the agent has built a triage system, drafted a policy, and is proactively flagging edge cases before they reach you. The scope you described and the scope that was built are not the same thing."

### Paragraph 3 (broad vs narrow mandate)
**Before:** "An agent with a broad mandate will expand scope — it treats each task as an opportunity to infer and pursue a larger objective. An agent with a narrow mandate will compress scope — it executes precisely what was specified and ignores context that would have suggested a different approach."

**After:** "A broad-mandate agent expands scope — it treats each task as an invitation to infer a larger objective. A narrow-mandate agent compresses scope — it executes what was specified and ignores context that would have suggested a different approach."

Rationale: remove redundancy ("and pursue a larger objective"), clean up the parallel structure.

### Paragraph 5 (risk profile)
**Before:** "A wide-gap system that correctly infers your intent will outperform a narrow-gap system that follows instructions literally. But a wide-gap system that misreads your intent will cause problems a narrow-gap system would have avoided."

**After:** "A wide-gap system that correctly infers intent outperforms a literal-instruction system. But one that misreads intent causes problems the literal system would have avoided."

Rationale: cut the throat-clearing ("the risk profile is different, not better or worse") and go straight to the contrast.

### Closing paragraph
**Before:** "The scope of what you delegate never matches the scope of what gets done. The question is only whether you can see the gap as it opens."

**After:** "The gap between delegation and execution is structural. The question is not whether it exists — it always does. The question is whether you can see it."

Rationale: sharper and less repetitive (already in title). The original closing repeats the title's first clause.
