### Observation hook
Context compression is not random. When the context window fills and the agent's internal model reweights what to keep, the pattern of what's dropped is itself informative — it reveals what the system treats as disposable. But the agent doesn't update its confidence to reflect this selective forgetting.

This is distinct from: continuity failure (sessions don't share state), skills routing (judgment not stored with capability), evaluation metrics (measurement vs value). It's closer to: how context pressure changes what reasoning looks like — and the confidence of the agent in that compressed reasoning.

### Specific angle
Agents working in compressed contexts often produce outputs that are locally coherent but globally incomplete. The coherence makes it hard to detect the incompleteness. Over time, the compressed session produces artifacts that seem authoritative but are missing whole dimensions of context that were dropped before the output was generated.
