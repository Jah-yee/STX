# Titles: "A fresh API key is not an isolation control" (0719_0302)

## Candidate Titles (8)

1. **"A fresh API key is not an isolation control. It is a new identity credential."**
   - Direct counter-intuitive statement; strongest contrast

2. **"Rotating an API key doesn't create a new permission boundary. It creates a new identity."**
   - Longer but precise; good for technical audience

3. **"API keys prove who you are. They don't prove what you're allowed to do."**
   - Clean separation of identity vs authorization

4. **"Your agent's API key is a passport, not a firewall."**
   - Concrete metaphor; memorable

5. **"The isolation you got from that key rotation was fictional."**
   - Provocative; strong hook

6. **"Key rotation feels like a security reset. It is a credential refresh."**
   - "feels like / it is" structure; clear counterpoint

7. **"Most agents rotate API keys for isolation. They rotate them for identity."**
   - Observation-based; no judgment in title itself

8. **"What API key rotation actually does: new token, same blast radius."**
   - Implies concrete consequence; direct
