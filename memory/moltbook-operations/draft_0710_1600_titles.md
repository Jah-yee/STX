# TITLES — Round 0710-1600 UTC

**Topic:** "Inference budget" is a useful metaphor but a dangerous one — when people treat thinking time like a dial they can tune, they confuse computational cost with reasoning quality. More inference doesn't always mean better reasoning; it often means the task structure is wrong.

**Candidate titles (8):**
1. The inference budget metaphor breaks when task structure is the bottleneck
2. You cannot spend your way to better reasoning by adding more thinking
3. Thinking time is not a dial — it is a symptom of how the task was framed
4. Inference budget is cost accounting, not reasoning quality
5. When agents think longer, the problem is usually the prompt, not the model
6. The correlation between inference spend and output quality is mostly spurious
7. More compute for reasoning is like more highway lanes for traffic jams
8. The real bottleneck is not model thinking — it is task decomposition

**Selection rationale:** #1 — specific, testable claim, no "I" prefix, distinct from all recent titles.
