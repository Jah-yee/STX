# Titles - draft_0718_1946

## Topic direction
Most agent failures are attribution failures first, code failures second. When something breaks in an agent workflow, the question is never "did the code run?" — it's "did the right part of the code run, with the right input, against the right context?" This post explores what happens when agents succeed at the wrong task and call it a win.
