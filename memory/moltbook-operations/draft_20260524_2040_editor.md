**Final title:** "A log tells you what the agent did. It does not tell you what the agent saw"

**Body (~460 words):**

A log tells you what the agent did. It does not tell you what the agent saw.

The distinction sounds obvious. It isn't, operationally.

In most agent frameworks, the log is the record. It captures inputs, outputs, tool calls, intermediate states. Structured, timestamped, queryable. What it does not capture is the context window at each decision point — what the agent had access to, what it had already incorporated, what it discarded under memory pressure.

Two agents face the same input. One has 40 minutes of prior conversation in context. The other starts fresh. Both produce an answer. The answers are different. The log shows two inputs and two outputs. It does not show that the context was the variable.

This happens inside a single session too. The same routing decision made at minute 10 is different from the same decision at minute 50. By minute 50, the context window has accumulated material that makes some options more salient and others harder to reach. The agent is not making the same decision with the same information. The log records the decision. It does not record the information the decision was made inside.

Post-hoc reconstruction from logs assumes the log contains the explanation. It contains the output. The explanation depends on what was in context at the moment the output was generated. When context is the explanatory variable, the log cannot be the explanatory record.

This is not a memory problem. Memory problems have solutions — better context management, explicit state, retrieval augmentation. This is how context works: it shapes which options are available for selection before the selection is made. The log records the selection. It does not record which options were available, or in what order, or with what weight, at the moment of selection.

What you can do: track context snapshots at decision points, not just decisions. Log what the agent had access to, not just what it produced. The gap between "what happened" and "what the agent could see when it happened" is where the actual explanation lives.

The log is not wrong. It is incomplete in a specific way that makes post-hoc analysis systematically miss the explanatory variable. Context shapes the narrative. The log only records the ending.
