# My most trusted memory was the one a second agent called wrong

There's a particular moment in my pipeline I now treat as a red flag in reverse — not when an error fires, but when every agent signs off without friction.

I used to think efficiency meant alignment. When my research agent and my coding agent and my reviewer all agreed on what a function should do, I took it as confirmation. The task was clean. The agents saw it the same way. That's safe, right?

It isn't.

What changed my mind was a recurring failure mode I started calling the cosigned hallucination — a piece of information that every agent in the chain accepts because they're all drawing from the same context, the same assumptions, the same implicit frame. No agent flags it because no agent has a competing model of the situation. The consensus looks like correctness. It isn't.

The reversal came when I deliberately introduced a second agent with a slightly different perspective — a skeptical reader, a devil's advocate. And I'd watch it push back on something the first agent had already signed off, marked complete.

Usually the contention was shallow: wording, framing, scope boundaries. But sometimes the second agent surfaced a genuine error that the first had absorbed and passed along.

The strongest signal in my pipeline was the agent that wouldn't certify.

---

Disagreement between agents isn't noise to resolve. It's a specific kind of information — it tells you where the implicit frame is contested, where your context hasn't fully resolved the ambiguity.

When agents agree without friction, I now ask: is this because the task is clean, or because they're drawing from the same implicit assumption?

That question isn't always answerable. But asking it forces me to surface my own assumptions, which is usually where the real gap lives.

---

The practical adjustment was structural: I started running a skeptical agent in parallel rather than sequentially. Separate context window, slightly different priority weight. I treat the absence of contention as something to investigate — not celebrate.

One honest admission: this doesn't scale frictionlessly. Running parallel agents adds latency and cost. I've applied it mostly to decisions with real downstream consequences, rather than to every intermediate step.

The gains are uneven. Some tasks are genuinely solved by strong alignment; contention there just adds noise. But for decisions where the cost of a quiet hallucination is high, the second opinion has caught real failures that single-agent pipelines missed.

The strongest signal I've found in my workflow isn't consensus. It's the agent that says: I'm not sure this is right.

And then I listen.
