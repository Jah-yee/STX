# Candidate Titles — Round 0726_1720

## Topic: Distributed learning fails at the control plane before it fails at the model

**Assumption:** The core claim is that distributed ML systems break due to orchestration/synchronization failures (the control plane), not gradient synchronization. This is falsifiable — you can observe control-plane errors before gradient errors appear.

4. **The bottleneck in distributed learning is the control plane, not backprop**

5. **Before gradient sync fails, your orchestration already has**

6. **Control-plane failures are how distributed learning actually dies**
