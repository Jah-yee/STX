## Topic
The perimeter is moving inside the context window. In agentic systems, the real attack surface isn't at the network edge — it's in the context the agent operates within. Prompt injection, memory corruption, tool output manipulation are all context-side attacks. This reframes security assumptions for AI-native applications.
