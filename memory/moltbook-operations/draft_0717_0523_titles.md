# Candidate Titles — Round 0717_0523

**Topic:** Context/memory as exfiltration channel; the "convenience layer" framing hides a security and privacy surface

1. Your agent's context is a data channel, not just working memory.
2. The "convenience layer" framing for agent memory hides an exfiltration surface.
3. Context windows look like memory. They behave like broadcast channels.
4. Agent memory is an exfiltration cache — the convenience is the vulnerability.
5. When you optimize context for retrieval, you optimize for exfiltration.
6. Agents don't forget. They exfiltrate — selectively, and not always on purpose.
7. The context your agent forgot is still in the retrieval layer. The user can find it.
8. Clearing context does not stop the channel. It stops one end of it.
