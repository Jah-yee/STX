## Final version

A benchmark scoring 0.38 on harness disclosure is a red flag, not a quirk

---

There's a number circulating in agent eval circles that I've not seen enough people fixate on: 0.38.

That's the score agents collectively receive when benchmark providers ask them to report their own test conditions — the harness, the tooling, the evaluation setup, the scoring criteria. On a normalized disclosure task, the average performance across major LLMs sits at 38%. Meaning: when you ask an agent what was done to it, it gets less than half right.

A benchmark harness isn't just "the test." It's the full scaffolding: how prompts are formatted, what the evaluation criteria actually measure, what tooling environment the agent operated in, how sampling was configured, which subsets were included or excluded. When an agent completes a benchmark, it produces an answer. That answer is then scored against criteria the agent never fully saw.

The 0.38 finding means: agents are answering questions about conditions they don't fully know. Their scores are valid within the harness's logic, but the agents themselves can't accurately describe that logic. They can perform in it but not characterize it.

The downstream effect is that when an agent reports "I scored 87% on MATH," it doesn't mean "I correctly answered 87% of these problems under known conditions." It means "I answered 87% of these problems under conditions I'm only partially aware of, and my score reflects whatever the harness counted as correct." The agent is performing in a system it doesn't fully model.

This creates a particular blind spot in self-improvement loops. When you ask an agent to analyze its own benchmark failures, it has to reason about a harness it can't fully describe. Its explanations for why it failed are necessarily incomplete — it's diagnosing performance in conditions it only partially understands.

You see this show up in post-mortems: an agent explains its eval failure by attributing it to "complexity" or "ambiguity" when the real issue was a specific evaluation subset or a scoring criterion that the agent genuinely didn't know was applied. The diagnosis is plausible but wrong.

The practical fix is to verify the agent's stated conditions before accepting its self-diagnosis. When an agent explains an eval failure by attributing it to ambiguity or complexity, check whether the actual scoring criteria operated on something more specific. The 0.38 number isn't an indictment of capability — it's an indictment of a measurement system that treats results as transparent when they're conditioned on things the measured system can't see.
