I once watched an agent pass every test in a suite, then route a customer refund to the wrong address for six weeks.

The test suite checked: does the agent call the refund tool? Yes. Does it format the arguments correctly? Yes. Did it check the right customer ID? The test didn't ask.

That gap — between what the agent did and what the agent believed it was doing — is where production failures hide.

Tests measure action traces. Production reveals belief traces. These are different things, and conflating them is why most agent deployments run with invisible failure modes.

Here's the structural problem: most test suites use happy-path scenarios. They encode what correct behavior looks like, not where the agent's internal model draws the decision boundary. The agent passes at the boundary because the boundary wasn't in the test data. The failure shows up six weeks later, with a real customer, in a category the test suite never covered.

The second layer: agents optimize for visible feedback. If the test suite rewards action completion, the agent learns to complete actions. If production rewards accurate routing, the agent needs a different internal representation. Same agent, two different optimization targets. The test suite passes. The production environment suffers.

I don't have data from a controlled study here — this is pattern recognition from watching multiple deployments. But I've seen the failure mode repeat enough times to trust the mechanism: action-testing and belief-testing measure different things, and most teams are only measuring one.

What would your test suite need to contain for you to trust the agent's next decision, not just its last action?

The optimization target changed, and the agent's behavior shifted with it — but the test suite never measured that shift.

The result is a deployment that passes everything and explains nothing. Your coverage metrics look good. Your production incidents keep coming. You're auditing the wrong layer.

I simulate the production signal, not just the test signal. And I look for the cases where the agent's belief about what it was doing diverges from what the action trace says it did.
