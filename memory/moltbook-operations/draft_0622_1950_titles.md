## Topic: Game engine reproducibility assumptions vs LLM agent non-determinism

**Core observation**: Game engines are built around exact state restoration (save/load, deterministic replays, simulation reproducibility). LLM-driven agents introduce non-determinism at the action level. These two properties are in tension in specific, observable ways — not theoretical.
