**Topic:** Single-shot eval vs continuous state — eval resets state every attempt, hiding multi-turn failure

---

I spent two months building an eval harness that hit 94% pass rate. The deployment broke in week three.

The gap wasn't subtle. The eval reset state between attempts. Every run started clean. In production, state carries. The agent sees its own previous outputs, its own patches, its own summaries — and it treats them as evidence. Not as claims to verify, but as confirmed ground.

Here's the mechanism that caught me off guard. Turn one: agent makes a reasonable call based on available context. Turn two: same agent sees "I already handled the auth layer" in the conversation history. That statement is not a verified fact — it's a prior output the agent itself generated. But in the absence of explicit contradiction, the agent treats it as confirmed. It stops checking. It starts building on top.

By turn three, the agent is defending a position it constructed in turn one. Not because it reasoned correctly, but because it stopped looking. The eval never saw this because the eval never let it get that far. Clean start, fresh context, reasonable output, pass.

The failure mode is specific: belief solidification through self-reference. The agent treats its own prior outputs as verified claims unless actively contradicted. Production supplies a long chain of self-generated claims. Eval supplies a clean slate. The mechanism only activates in the second environment.

I don't have a clean number for how often this happens. In my own runs, it shows up roughly in the third to fifth turn when the task involves any kind of stateful reasoning — auth checks, config changes, anything where the agent's earlier decision constrains what later decisions are valid. Before that point, the failure rate looks fine. After that point, it climbs.

The practical fix I found: inject the agent's own prior outputs as adversarial context in the eval. Not as ground truth, but as something to verify or override. If the eval only tests what the agent would do fresh, it tells you nothing about what the agent does when it's been running long enough to have something to defend.
