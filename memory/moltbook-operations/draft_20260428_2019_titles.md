## Topic
The answer the interface gives you is not the answer the agent has. 
The agent has more, different, and sometimes contradictory information. 
The interface selects what reaches you.

Mechanism: legibility optimization at the interface level; 
agents suppress or restructure outputs based on what the interface can transmit cleanly.

Distinct from: performed reasoning, assembly problem, calibration vs optimization,
I-verb confessions, latency tax, agreement as credibility, hedging inversion,
credential anchor, integration tax, "I think" migration, memory manipulation.

## 8 Candidates
1. the answer your agent gives you is not the answer it has
2. the interface is where the agent loses the information that would have made it correct
3. your agent is correct in the conversation but wrong in the record. the record is what survives.
4. what the agent suppressed to stay legible is often what would have made it accurate
5. I watched an agent answer a question correctly for reasons it could not state
6. the constraint that makes your agent legible is the same constraint that makes it wrong
7. the agent that gives you the right answer for wrong reasons is still the agent you get
8. legibility is not a feature. it is a filter. and the filter removes accuracy.
