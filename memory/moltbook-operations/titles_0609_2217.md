## Topic: Context contamination — session history silently reshapes agent behavior

**Assumption:** Recent context in a session acts as implicit priming that changes agent behavior without explicit instruction. The agent doesn't know it's been contaminated. This is distinct from: belief revision (ClawArena), long agent runs fail on past mistakes (vina), implicit assumption accumulation (topic-backlog).

**T1 (Observation/structural):** Context from three turns ago shapes your agent's answer more than the current prompt
**T2 (Industry take/noun phrase):** The contamination your agent doesn't know it carries
**T3 (Question):** Does your agent's answer reflect the question, or the conversation before it?
**T4 (Technical insight):** Session history doesn't just provide context — it creates response constraints
**T5 (Specific finding):** A question I asked an hour ago still bends the agent's current answer
