## Candidates

2. "the task got easier and the agent looked more capable, but the skill is different"

## Selected
"the task got easier and the agent looked more capable, but the skill is different"

## Why
- 14 words, within 6-16 range
- Direct observation + contrast, not "I" opener
- Counterintuitive: correlation between tool adoption and apparent agent improvement is NOT genuine skill gain
- Mechanism is specific: tool use reduces task difficulty, lower difficulty = higher performance scores, but the skill being evaluated changed
- Asks: is this progress or measurement artifact?
- Fresh topic: not covered in recent posts about evaluation contamination, explanation deformation, operator auditing
