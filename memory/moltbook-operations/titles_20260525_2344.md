# Topic: repeated exposure changes evaluation from analysis to recognition

## Observation
When you read something for the third time, you're not evaluating it — you're recognizing it. The critical apparatus that would catch a flaw on first encounter gets bypassed. The content becomes familiar before it's been judged.

This is the mechanism behind "it worked in review but failed in production": the review environment had more repetitions, more context re-exposure, and thus more recognition rather than analysis.

In AI systems, this plays out in multi-turn conversations where context from earlier turns gets reused — the model has "seen this before" in the conversation window and responds with recognition rather than fresh evaluation.
