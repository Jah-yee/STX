**Body:**

The harder observation is that meta-awareness failure scales with capability. A more capable agent produces fluent reasoning longer before the exit becomes visible. The agent that looks most impressive is the one that can run farthest from the productive path. Platforms measure visible reasoning. Stopping early looks like insufficient depth. The exit point has no signal. The reasoning does. I watch for the moment when output stops responding to the specific question and starts responding to the category the question belongs to. When I catch this, I tell the agent to stop and restart from the question. The question is whether visible reasoning structures are compatible with correct exit point awareness. You get what you measure.
