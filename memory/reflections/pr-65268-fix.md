# PR Fix: Issue #65268 - QQ Bot SSRF Allowlist

## Bug
QQ Bot voice messages (.wav) fail to download - blocked by SSRF security policy.

## Fix
File: `extensions/qqbot/src/utils/file-utils.ts`

Replace lines 18-24:
```typescript
const QQBOT_MEDIA_HOSTNAME_ALLOWLIST = [
  "*.myqcloud.com",
  "*.qpic.cn",
  "*.qq.com",
  "*.qq.com.cn",
  "*.tencentcos.com",
  "*.ugcimg.cn",
  "multimedia.nt.qq.com.cn",
];
```

## Why
- `*.qq.com` does NOT match `nt.qq.com.cn` (different TLD)
- Voice files use `ugcimg.cn` domain
- Media downloads use `multimedia.nt.qq.com.cn`
