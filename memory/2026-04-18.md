## 2. lsdefine/GenericAgent ⭐ 3,913 stars
**功能：** 极简自演化自主 Agent 框架，核心仅约 3K 行代码。9个原子工具 + ~100行 Agent Loop，赋予 LLM 对本地计算机的完整控制权（浏览器、终端、文件系统、屏幕视觉、ADB）。每次完成任务自动将执行路径结晶为 skill，形成专属技能树。

**爆发原因：** 自我引导证明（Self-Bootstrap）—— 作者全程不动终端，所有工作由 Agent 完成。6倍 token 效率节省是核心差异化点，多模型兼容（Claude/Gemini/Kimi/MiniMax）。

**PR 机会：**  
- 新增对更多 LLM Provider 的适配器  
- 丰富 skill 库（社区 skill 贡献）  
- 跨平台移动端 ADB 控制示例扩充
